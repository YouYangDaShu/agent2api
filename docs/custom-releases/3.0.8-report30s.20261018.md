# Agent2API 3.0.8-report30s.20261018

这是基于官方 **3.0.8** 的自用服务端修复版，非官方新正式版。源码基线为 `68d0a4e4bfd8dc5a1daa296c61e0cc0b10a871da`。

## 本次变化

- 报表默认自动刷新间隔由 1 秒调整为 30 秒，前后端默认值保持一致。
- 已保存的用户自定义间隔保持不变，包括显式设置为 1 秒的情况。
- 新增配置回归测试，覆盖默认值和显式自定义值；重建入库前端产物。
- 同步五处版本标识与 Cargo.lock，以便区分官方 3.0.8 和本次自用构建。

## 上游已包含的修复

官方 3.0.8 已吸收此前报表优化：窄列投影读取、`requests` 覆盖索引（schema v15）、多窗口聚合下推 SQL、同步读库移出异步执行线程、数据未变化时避免整页重绘。本次沿用官方实现，不重复移植旧补丁。

另附一次性升级工具 `scripts/align-report-index.py`：仅在备份或已停止服务的库上运行，识别旧三列索引并事务化替换为官方七列索引；遇到未知列序则拒绝操作，不修改账号或请求记录，不代替应用的 schema 迁移。

schema v15 的覆盖索引为 `(ts, is_test, model, upstream_model, total_tokens, cache_read_tokens, prompt_tokens)`，不是旧自用补丁中的同名三列索引。升级前需在完整生产快照上验证旧同名索引是否存在及实际列序。

## 上游可用性说明

核验时官方 GitHub 仓库网页、REST API、Git fetch 与 raw 路径均返回 404，因此无法确认仓库最新 HEAD。官方 Docker Hub 的 `latest` 指向 `3.0.8`；另有 `3.0.9-beta.1` 预发布镜像，未作为本次生产基线。Docker 官方 3.0.8 的 OCI revision 为上述 `68d0a4e`，与本地保存源码相同。

## 构建、验证与部署边界

所有编译均在本地工作站执行，生产服务器只接收和运行已编译产物。Linux amd64 服务端和容器镜像是本次交付目标，Windows/macOS 桌面安装包不在范围内。测试、制品 SHA256、快照迁移和部署结果见同 Release 的构建清单及校验文件。

升级保留原数据卷、账号密钥、账号、代理、优先级和并发配置。切换前留存完整在线数据库快照、旧容器镜像、Compose 配置与回滚材料。schema v15 增加索引后，旧 3.0.7 可能拒绝打开新版本库，回滚不能只换镜像：需停下新服务，保存切换后数据，再按备份恢复旧 schema 后运行旧镜像。
